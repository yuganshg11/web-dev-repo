# P10 - Portfolio header and footer with advanced Flexbox

## Aim
Create a portfolio header and footer and use Flexbox to align their contents.

## Files
- `index.html` contains the header, main content and footer.
- `style.css` handles alignment and responsive behaviour.

## CSS concepts
The header uses Flexbox to keep the logo and navigation apart. The footer has separate groups that wrap on smaller screens. The `gap`, `justify-content`, `align-items` and `flex-wrap` properties control the layout.

## Run
Open `index.html` and resize the browser.
