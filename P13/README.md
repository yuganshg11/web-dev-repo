# P13 - Choosing between Flexbox and Grid for a shared layout

## Aim
Compare Flexbox and CSS Grid and use each where it makes sense in one page.

## Files
- `index.html` contains a shared page with navigation and content cards.
- `style.css` uses Flexbox for the navigation and Grid for the card layout.

## Comparison
Flexbox is useful when arranging items in one direction, such as a row of navigation links. Grid is useful when arranging content in rows and columns, such as a group of cards.

Neither layout method is always better. The choice depends on the shape of the layout.

## Run
Open `index.html` and resize the browser to see how both layouts respond.
