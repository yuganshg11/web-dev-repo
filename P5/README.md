# P5 - Semantic bio page

## Aim
Make a small personal bio page using semantic HTML elements.

## Files
- `index.html` contains the page structure.
- `style.css` contains all page styling.

## What I used
The page uses a header, main section, article, and footer. The information is split into clear sections so the page is easy to read. The CSS is linked using a separate stylesheet.

## Run
Open `index.html` in a browser.

## Result
A simple bio page with semantic HTML and external CSS.
