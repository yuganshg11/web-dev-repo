# P12 - Portfolio projects grid with advanced CSS Grid

## Aim
Display portfolio projects in a grid with different card sizes using CSS Grid.

## Files
- `index.html` contains the project cards.
- `style.css` controls the grid columns, rows and responsive layout.

## CSS concepts
The grid uses `grid-template-columns`, `grid-auto-rows` and `grid-column` / `grid-row` placement to make one project stand out. At smaller widths the cards return to a simple one-column layout.

## Run
Open `index.html` in a browser. Replace the sample project details with your own work.
