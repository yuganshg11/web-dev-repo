# P11 - Newspaper-style three-column layout with CSS Grid

## Aim
Create a newspaper-style page with three columns using CSS Grid.

## Files
- `index.html` contains the news-style sections.
- `style.css` defines the grid and responsive layout.

## CSS concepts
The main layout uses `display: grid` with three columns. The lead story spans more space than the side stories. On a smaller screen the columns become a single column so the text stays readable.

## Run
Open `index.html` in a browser and resize the window.
