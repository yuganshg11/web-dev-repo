# P9 - Responsive navbar and card grid using Flexbox

## Aim
Build a navigation bar and a set of cards with Flexbox. Make the layout adjust for smaller screens.

## Files
- `index.html` contains the navbar and cards.
- `style.css` contains the Flexbox rules and media query.

## What I used
The card container uses `display: flex` and `flex-wrap: wrap`. Each card has a flexible width, and the media query changes the layout for narrow screens.

## Run
Open `index.html`. Resize the browser to check the responsive layout.
