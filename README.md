# Web Development - I Laboratory

This repository contains my work for the Programming for Web Development - I lab.

## Lab work

| Program | Topic |
|---|---|
| P1 | Project folder and terminal navigation |
| P2 | Portfolio repo with an initial commit |
| P3 | Feature-branch Git workflow |
| P4 | GitHub README and version tags |
| P5 | Semantic bio page |
| P6 | Portfolio page structure in semantic HTML |
| P7 | Design tokens and typography in CSS |
| P8 | Sticky navbar and card overlay |
| P9 | Responsive navbar and card grid using Flexbox |
| P10 | Portfolio header and footer with advanced Flexbox |
| P11 | Newspaper-style three-column layout with CSS Grid |
| P12 | Portfolio projects grid with advanced CSS Grid |
| P13 | Choosing between Flexbox and Grid |

Each program has its own folder. The HTML and CSS files are kept separate wherever a webpage is part of the exercise.

## How to view a page

Open the required program folder and open its `index.html` file in a browser. The stylesheet is linked externally from the HTML file.

## Note

The first four programs focus on terminal and Git commands, so their steps and command examples are written in their README files.
