# P6 - Full portfolio page structure in semantic HTML

## Aim
Build the main sections of a portfolio page with semantic HTML.

## Files
- `index.html` - page content and structure.
- `style.css` - layout, colours and spacing.

## Sections
The page includes a header and navigation, an introduction, an about section, selected work, skills and a contact section. Each part has a meaningful HTML element.

## Run
Open `index.html` in a browser. Replace the sample text and project details with your own information before submission.

## Result
A complete one-page portfolio layout using semantic elements.
