# P7 - Design tokens and typography system in CSS

## Aim
Create reusable CSS variables for colours, spacing and typography, then use them throughout a page.

## Files
- `index.html` has a small sample page.
- `style.css` contains the design tokens in `:root`.

## What to notice
The custom properties such as `--color-primary`, `--space-medium` and `--font-body` are defined once and reused. Changing a token updates every place where it is used.

## Run
Open `index.html` in a browser.
