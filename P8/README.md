# P8 - Sticky navbar and card overlay using CSS positioning

## Aim
Use CSS positioning to keep the navigation bar at the top while scrolling and place a label over a card image.

## Files
- `index.html` - sample content and card.
- `style.css` - sticky and positioned elements.

## What I used
The navigation uses `position: sticky` with `top: 0`. The card is positioned relative to its own box, and the label uses absolute positioning so it sits over the image.

## Run
Open `index.html` and scroll down to see the sticky navigation.
