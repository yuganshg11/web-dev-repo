# P1 - Project folder and terminal navigation

## Aim
Create a project folder and learn how to move between folders using the terminal.

## Steps

1. Open Terminal.
2. Move to the place where you want to keep your lab work.
3. Create a folder for the project.
4. Move into the folder and check the current location.
5. Create the basic files and list them.

## Commands used

```bash
pwd
ls
mkdir web-lab
cd web-lab
mkdir P1
cd P1
touch index.html style.css
ls
```

- `pwd` shows the current folder.
- `ls` lists the files and folders.
- `mkdir` creates a new folder.
- `cd` changes the current folder.
- `touch` creates an empty file.

## Result
A project folder was created and I practised moving between directories and checking their contents.
